{% comment %} The AI chat: a round button pinned to the bottom-right corner of the screen that opens a chat panel (Sprint 3 Section 3). Included once, from base.html. Hovering the button (or the space just to its right) shows a small arrow that slides the button off the right edge; a small tab stays at the edge to bring it back. See chat.js and the "AI chat" block of style.css. While a request runs, chat.js polls data-status-url so a schedule generation shows its progress, and after one succeeds it offers a link to data-viewer-url (or refreshes the Schedule Viewer if that is the page being shown). The button, the arrow and the tab all start hidden and gui/static/gui/js/chat.js reveals them, so a browser without JavaScript never shows a chat that cannot work (the same progressive-enhancement rule as the rest of the app). The panel posts one request at a time to gui:assistant_ask (gui/views_ai.py, which hands it to gui/ai/service.py); it never sees or sends an API key. The conversation is kept on the server (gui/ai/chats.py): chat.js draws the saved chat again on every page; the history sidebar starts a new chat, opens an older one or deletes it. {% endcomment %}
